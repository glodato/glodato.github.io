# Giuseppe Lodato

Sito personale accademico per https://glodato.github.io/.

I file sono pronti per GitHub Pages e non richiedono compilazione.

## Pubblicazione

1. Crea un repository pubblico chiamato esattamente glodato.github.io nell’account glodato.
2. Carica i file di questa cartella nella radice del repository (index.html deve essere visibile direttamente).
3. Apri Settings → Pages. In Build and deployment seleziona Deploy from a branch, branch main, cartella / (root), poi Save.

## Aggiornamenti

Modifica index.html per testi, link e pubblicazioni; style.css contiene la grafica. Le immagini sono nella stessa cartella. Le modifiche pubblicate sul ramo main vengono riportate sul sito automaticamente.
